# ENSF 619 – Assignments

Green AI experiments on code docstring generation with small language models.

| Folder | Assignment |
|---|---|
| [`Assignment_1/`](Assignment_1) | Green Prompt Engineering: prompts, models, and quantization levels compared on token count, latency, energy, and accuracy |
| [`Assignment_2/`](Assignment_2) | Environmental impact of model compression: quantization, pruning, and knowledge distillation measured with CodeCarbon |
| [`tools/`](tools) | Helper script to build the PDF reports from Markdown |

Each assignment folder has its own README with setup and reproduction steps.
